# Number Guessing Game

This game allows you to check your luck and intuition :)
The computer picks a secret number and you try to find it.

### How to play
- The secret number is between **1 and 9**.
- You get **5 tries** to guess it.
- After each guess you are told whether to aim **higher** or **lower**.
- The game ends when you guess correctly or run out of tries (it always tells
  you the final result and reveals the number if you lose).

### Input rules
- Enter a single whole number between 1 and 9.
- Empty input, letters, decimals or out-of-range numbers are rejected with a
  friendly message and you are asked again. Invalid entries do **not** use up
  one of your 5 tries.

### Usage
Just run `python main.py` in the command line after setting the project directory.
