# Number Guessing Game

Test your luck and intuition! Guess the number the computer has picked.

## Rules

- The computer picks a random integer between **1** and **9** (inclusive).
- You have exactly **5 attempts** to guess it.
- After each wrong guess the game tells you whether your guess was too high or too low.
- If you guess the number within 5 attempts you win; otherwise the game reveals the answer.
- After each round you can choose to play again.

## Input Rules

- Enter a **whole number** between 1 and 9.
- Empty input, letters, or numbers outside the valid range are rejected with a friendly message — just try again.

## Usage

```bash
cd projects/Number_guessing_game
python main.py
```
